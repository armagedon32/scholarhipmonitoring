Dataset Description

The dataset contains {{ record_count }} student records, with each record representing a scholarship student/performance observation used for retention analysis. The dataset is composed of historical scholar records from the previous scholarship cycles of Kolehiyo ng Subic and primarily captures the following information:

  • Academic performance — GWA, number of failed subjects, and units enrolled
  • Attendance — class attendance rate
  • Scholarship information — scholarship type or program
  • Socioeconomic information — socio-economic status and annual family income
  • Retention status — whether the scholar was retained (1) or at-risk (0) for the period
